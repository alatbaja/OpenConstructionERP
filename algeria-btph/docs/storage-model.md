# نموذج التخزين للملفات المرفوعة (BTPH)

## الأفكار الأساسية
- الملفات المرفوعة (صور توقيع، موافقات، سجلات تدقيق، PDFs) تُرفع مرة واحدة عبر المسار المختار
- يُحفظ المسار أو الرابط فقط داخل `InvoiceDocumentFile.file_path`
- يُفضل التخزين المحلي عند التطوير، ويمكن لاحقًا الاتصال بـ S3/MinIO/Storage خارجي

## الهيكل المقترح للتخزين
```
/storage/
  /invoices/
    /BT-2026-001/
      signature.png
      approval.png
      audit_log.json
    /BT-2026-002/
      ...
  /uploads/ (temp)
```

## ملاحظات هامة
- يُحفظ المسار فقط داخل قاعدة البيانات أو النموذج
- لا يُخزن الملف كـ bytearray داخل قاعدة البيانات مباشرة إلا إذا لزم الأمر
- يُمنع تخزين المسار النسبي غير الواضح؛ يُفضل المسار المطلق أو المسار الكامل بالنسبة لـ storage الإعدادي
